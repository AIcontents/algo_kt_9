# КТ_9: решения на Java

Шесть задач, каждая — один самодостаточный файл `Main.java`: только стандартная библиотека, ввод из stdin, вывод в stdout, совместимо с Java 8 и новее. В начале каждого файла — комментарий с идеей решения и оценкой сложности.

## Структура

```
task3/Main.java        решение задачи 3
task3/examples/        примеры: 1.in / 1.out, 2.in / 2.out, 3.in / 3.out
```

## Запуск

```
cd task3
javac Main.java
java Main < examples/1.in
```

В проверяющую систему отправляйте `Main.java` из нужной папки (класс называется `Main`).

## Допущения

Особых допущений нет: ввод и вывод — как в условии.

## Задачи

| № | Задача | Идея | Сложность |
|---|---|---|---|
| 1 | Минимум палиндромов в разбиении строки | расширение от центров + dp | O(n²) |
| 2 | Маршруты в сетке с препятствиями | динамика по строке, по модулю 10⁹+7 | O(nm) |
| 3 | Независимое множество максимальной ценности в дереве | take / skip, без рекурсии | O(n) |
| 4 | Стоимость слияния соседних групп | интервальная динамика + префиксные суммы | O(n³) |
| 5 | Путь с «экранами» на отрицательных клетках | dp[клетка][число экранов], хранится одна строка | O(n·m·k) |
| 6 | Ровно k связных вершин дерева с максимальной суммой | рюкзак на поддеревьях | O(n·k) |

## Как проверялось

- Каждая из шести программ сверена с простым перебором на Python на 200–300 случайных мелких тестах (плюс примеры из условия и граничные случаи).
- Для задач 3–6 — отдельные тесты со значениями до 10⁹ по модулю, чтобы поймать переполнение `int`.
- Входы максимального размера из ограничений запускались с `-Xmx256m`: каждая программа укладывается примерно в 0,7 с на одном ядре; результаты сверялись с независимыми реализациями на Python/numpy.
- Все примеры из папок `examples/` прогнаны на чистой сборке.
